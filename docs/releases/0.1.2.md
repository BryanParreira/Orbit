# Orbit 0.1.2

## Delete machines completely

- **Delete** now removes a machine for good and frees the space right away, instead of leaving gigabytes in the Trash. *Move to Trash* is still there if you want it.
- The delete window shows exactly what's removed and how much space you get back.
- The installer Orbit downloaded for that machine is removed too, when no other machine uses it. Files you added yourself are never touched.
- **Settings → Storage → Clean up** finds leftovers from interrupted downloads, unfinished imports or machines that didn't stop cleanly, and explains each one.
- Press **⌘⌫** in the sidebar to delete the selected machine.

## Fixed

- Connecting a drive could make a newly created machine appear twice, and starting the copy would open the same disk twice. Machines copied in Finder now get their own identity.
- Cancelling a macOS installation no longer starts the unfinished machine.
- Finishing a large download no longer freezes Orbit when your library is on another drive.
- Shutting down or logging out of your Mac no longer waits on a dialog; running machines are suspended automatically.
- Quitting during a download or installation now tells you it will be cancelled.
- The low-disk protection now works on external drives too.
- Windows snapshots include the emulated TPM.
- Lower memory use with many machines.
