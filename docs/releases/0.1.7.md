# Orbit 0.1.7

## New

- **Automatic snapshots**: turn them on in a machine's settings (Advanced) and Orbit takes a snapshot daily or weekly as the machine starts. The newest three are kept; snapshots you take yourself are never removed
- **Revert to Last Snapshot…** in the Machine menu goes back to the newest snapshot in one step
- **Start when Orbit opens**: for machines you always want running. Suspended ones resume where they were
- **Keep on Top**: the pin button in a machine's window keeps it above other apps, so you can watch the guest while you work on your Mac
- **Send Ctrl-Alt-Delete** for Windows machines, from the Machine menu

## Security

- Machines from elsewhere can no longer reach files on your Mac. A package that contains links to other files isn't imported, and a machine whose package contains one won't start
- Imported machines lose any installer kept outside their own package and any port forwards, as they already lost shared folders and custom QEMU arguments. Each could give a machine someone else made access to your Mac or your network
- Disk images that name other files (a QCOW2 or VMDK backing file, an external data file, pieces of a split disk outside its folder) are refused when imported and, for QCOW2, every time a machine starts
- Settings that reach QEMU's command line (the network address and the machine type) are checked, so they can't carry extra options, and installer discs are never probed for a format
- Ejecting an installer only ever deletes a file Orbit put inside the machine
- The Windows download sheet shows only Microsoft's own pages; other links open in your browser
- UTM imports get the same checks as Orbit packages

## Fixed

- QEMU machines with a comma in their name (“Lab, test”) couldn't start
- A damaged snapshot no longer discards a suspended machine's saved session when it can't be restored
- Snapshots can't be restored while a machine is still downloading or installing
- Importing a second copy of a machine you already have gives the copy its own network and hardware identity, so both can run
- Disks can't be resized while a machine is suspended, when its saved memory still expects the old size
- Port forwards accept only real port numbers (1–65535)
- The library can't be moved into a machine's package or a folder Orbit can't write to
