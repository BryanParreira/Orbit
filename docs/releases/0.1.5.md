# Orbit 0.1.5

## Fixed

- **Linux installers could fail at partitioning.** The installer disc was attached as a USB drive, so installers such as Kali's and Debian's listed it as the first disk (“SCSI1 … Apple Virtual Disk”) and preselected it, and partitioning it failed. The installer is now attached after the machine's own disk, which is listed first and chosen by default.
