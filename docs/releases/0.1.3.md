# Orbit 0.1.3

## New

- **Port forwarding for every system**: forward a Mac port to a server inside any machine, so your Mac and other devices on your network can reach it
- **Choose where each machine is kept**: put a new machine in any folder or drive, such as an external SSD when your Mac is short on space. Everything it uses, including the installer it downloads, stays there
- **Move machines**: Move… takes a machine to another folder or drive with everything it uses. It's instant on the same drive, and on another drive the original is removed only once the copy is complete. Move to Library brings it back
- The machine page shows where each machine is kept. Settings → Storage lists machines kept elsewhere, and machines on a disconnected drive come back when you reconnect it
- **Download Windows 11 inside Orbit**: choose Windows 11 and Microsoft's download page opens right in the app. Pick a language and Orbit downloads, verifies and installs it like every other system
- **Windows 11 sets up by itself**: Orbit adds the drivers Windows on ARM needs, so setup goes online like on a PC. No more skipping the network and installing drivers by hand. It also answers *Press any key to boot from CD* on the first start
- Drivers come from the virtio-win project, pinned to one verified release, and are downloaded only once

## Fixed

- **Windows machines with an emulated TPM couldn't start**: Apple Silicon refused the chip. They start now
- **Windows 11 needs nothing extra**: setup no longer requires a TPM chip, so Windows installs on every Apple Silicon Mac with just QEMU. Install swtpm yourself to give a machine an emulated TPM
- Ejecting an installer that was downloaded into a machine frees its space
- Opening Orbit with machines on an external drive no longer looks frozen while macOS asks for access to the drive
- Windows starts from its disk once installed, instead of waiting at “Press any key to boot from CD” while the installer is attached
- Windows machines show a live preview in the library, and the Storage figure stays current while machines run
- Downloads show progress while they're verified
- Large downloads pick up where they stopped when the connection drops, instead of failing. Connection errors say what actually happened
- Orbit no longer gets slowed down by App Nap while it downloads, installs or runs machines in the background, and keeps the Mac awake for downloads and installs
- QEMU commands can no longer hang: each has a time limit, and replies are matched to the right command
- FreeBSD (and other non-Linux ARM systems) no longer freeze on the boot logo: they get a display their console can draw on
- Windows shows the right time from the first start
- Rocky Linux and AlmaLinux explain their dark first minutes (the installer checks its disc) instead of looking stuck

## Tested

Every system in the catalog was downloaded from its official server, verified, created on an external drive and booted in Orbit: Ubuntu 26.04 Desktop and Server, Fedora 44, Debian 13.7, Kali 2026.2, Rocky 10.2, AlmaLinux 10.2, openSUSE Tumbleweed, NixOS 26.05, Alpine 3.24, FreeBSD 15.1 and an emulated x86-64 PC. Windows 11 on ARM was downloaded inside Orbit, installed without a TPM and went online during setup
