# Orbit 0.1.4

## Fixed

- **Large downloads no longer look stuck at 100%.** Downloads now go straight into the machine's own folder as they arrive. Before, a finished download was copied from the system's temporary folder into place, which for Windows (9 GB) or macOS (27 GB) on an external drive took minutes while the progress bar sat at 100%.
- Downloads no longer need free space on your Mac's own disk when the machine is kept on another drive.
- A download whose connection drops picks up from the bytes already saved, even on servers that hand out one-time links, such as Microsoft's.
