# Orbit 0.1.0

The first release of Orbit: virtual machines at native speed for Apple Silicon.

## Highlights

- **Native speed** for macOS and ARM Linux on Apple's own hypervisor
- **Two-step setup** that downloads the newest Ubuntu, Fedora, Debian, Alpine or macOS for you
- **Suspend and resume** in under a second, so quitting Orbit never loses your place
- **Instant snapshots, duplicates and disposable sessions** using APFS clones
- **Bring your own files**: ISO installers, macOS restore images, and disks from UTM, VMware, VirtualBox or Hyper-V
- **Windows 11 and x86 guests** through QEMU, which Orbit can install for you
- **Automatic updates** from inside the app

## Requirements

A Mac with Apple Silicon running macOS 26 or later.
