# Orbit 0.1.1

## New

- **All Machines gallery**: every machine as a large live preview, with start, pause, suspend and shut-down right on the card
- **Seven new systems**: Kali Linux, Ubuntu Server, Rocky Linux, AlmaLinux, openSUSE Tumbleweed, NixOS and FreeBSD
- **Text size for Linux**: guests now match the size of macOS on Retina screens, adjustable live from the machine's toolbar (Sharp, Medium, Large)
- **Simpler settings**: Light, Balanced and Maximum performance presets, a summary header and clearer explanations
- **Storage panel** in Settings showing everything Orbit keeps on your Mac, with sizes, and a way to remove unused downloads
- **Help menu** with a full user guide

## Safer

- Every download is verified against the checksum its project publishes
- Machines received from someone else can't reach files elsewhere on your Mac and start without shared folders
- Clipboard sharing is now off unless you turn it on
- Machines can't take the memory macOS needs, and pause themselves before the disk fills up

## Fixed

- A crash when opening a machine's settings
- Machine windows now open at a size that fits your screen
- Previews show the whole guest screen instead of cropping it
- Many smaller reliability fixes for starting, stopping and importing machines
